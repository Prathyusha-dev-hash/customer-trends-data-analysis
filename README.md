# Customer Shopping Behavior Analysis

An end-to-end data analysis project exploring customer shopping trends, purchasing behavior, and product performance using **Python**, **SQL**, and **Power BI**.

---

## 📌 Project Overview
- **Goal:** Analyze customer demographics, purchase patterns, discount impacts, and subscription behavior to generate actionable business insights.
- **Tech Stack:** Python (Pandas), SQL (PostgreSQL), Power BI.

---

## 📁 Repository Structure

```text
├── customer_shopping_behavior.csv            # Raw customer dataset
├── Customer_Shopping_Behavior_Analysis.ipynb    # Data cleaning & exploratory analysis
├── customer_behavior_sql_queries.sql         # SQL business queries & customer segmentation
├── customer_behavior_dashboard.pbix          # Interactive Power BI dashboard
├── Business Problem Document.pdf             # Project objectives & problem statement
├── Customer Shopping Behavior Analysis.pdf    # Summary report
└── Customer-Shopping-Behavior-Analysis.pptx   # Final presentation deck
```

---

## 🔍 Key Analysis & Insights
- **Revenue & Demographics:** Analyzed sales breakdown across customer gender, age groups, and categories.
- **Discounts & Subscriptions:** Assessed how promotions and subscription status influence average purchase amount and total spend.
- **Customer Segmentation:** Grouped shoppers into New, Returning, and Loyal cohorts based on purchase history.
- **Visualization:** Built interactive Power BI reports to track sales KPIs and shopping trends.

---

## 🚀 How to Use
1. **Python Analysis:** Run `Customer_Shopping_Behavior_Analysis.ipynb` in Jupyter Notebook or VS Code for data preprocessing and exploratory data analysis.
2. **SQL Queries:** Import `customer_shopping_behavior.csv` into your SQL database and run `customer_behavior_sql_queries.sql`.
3. **Power BI Dashboard:** Open `customer_behavior_dashboard.pbix` in Power BI Desktop to interact with the visualizations.
